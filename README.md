# Servicio de aplicacion para la gestión de franquicias

El proyecto Franchise Network Management es una aplicación Spring Boot que proporciona una API RESTful para gestionar franquicias, sucursales y productos. La aplicación permite a los usuarios crear franquicias, añadir sucursales a las franquicias, gestionar productos en las sucursales y realizar un seguimiento del inventario de productos.
### Operaciones

- Crear una franquicia
- Añadir una sucursal a una franquicia
- Agregar y eliminar productos de una sucursal
- Modificar el stock de un producto en una sucursal
- Obtenga el mejor producto de una sucursal
